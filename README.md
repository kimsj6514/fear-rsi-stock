# Fear-RSI STOCK v1.0

기존 코인용 Fear-RSI와 **완전히 별도**로 배포하는 한국 주식 매수·매도 참고 신호 앱입니다. 자동 주문은 하지 않습니다.

## 기능
- 코스피·코스닥 시가총액 상위 **일부** 종목 일봉 매수 후보 탐색 (기본 80개, 대시보드에서 30~200개 조절)
- 관심 종목 1시간·4시간·일봉 RSI(14) 분석. 1시간봉과 4시간봉이 모두 같은 신호일 때만 강한 신호.
- 시장 심리는 **코스피 RSI와 미국 VIX**를 참고한 대체 지표입니다. 공식 한국 주식 공포탐욕지수가 아닙니다.
- 30거래일 고점 대비 하락률, 5일/20일 평균 기반 일봉 추세, 네이버 금융 링크.
- GitHub Actions 평일 한국시간 10:40, 12:40, 14:40, 16:40 전후 예약 검사 (UTC 01:40,03:40,05:40,07:40). 지연/누락 가능.
- 텔레그램 새 신호/단계 변경만 발송, `stock_alert_state.json` 중복 방지, `stock_signal_history.csv` 발송 당시 종가 기록.

## 중요한 데이터 한계
- 일봉 탐색은 전체 코스피·코스닥 전수 조사가 아니라 시가총액 상위 일부를 조회합니다. 종목 목록 로딩 실패 시 기본 종목 목록으로 대체되며 앱에 표시됩니다.
- 자동 탐색 결과는 **일봉 1차 후보**일 뿐, 1시간+4시간 동시 확인된 강한 매수가 아닙니다. 관심 종목에서 상세 확인하세요.
- 야후 금융의 한국 주식 분봉은 제공 여부/기간/지연이 제한될 수 있습니다. 미제공 시 신호를 만들지 않고 오류/자료 부족으로 표시합니다.
- 한국 주식의 4시간봉은 정규장 09:00–13:00(4시간), 13:00–15:30(2.5시간)으로 정의한 사용자 정의 봉입니다. 마지막 봉은 장 마감 후 확정됩니다.
- 가격은 확정봉의 종가이며 실제 현재 체결가가 아닐 수 있습니다. 매수/매도 신호는 수익을 보장하지 않습니다.
- 해외 VIX는 국내 투자 심리와 완전히 일치하지 않습니다.

## 새 저장소 배포 (기존 코인 저장소에 업로드하지 마세요)
1. GitHub에서 `fear-rsi-stock` 같은 **새 저장소**를 만듭니다.
2. ZIP의 `app.py`, `signals.py`, `notify.py`, `requirements.txt`, `README.md`를 새 저장소의 최상위 경로에 업로드합니다.
3. `.github/workflows/stock-alert.yml`도 **같은 경로**로 추가합니다.
4. Streamlit Community Cloud에서 새 저장소의 `app.py`를 새 앱으로 배포합니다.
5. 새 저장소 Settings → Secrets and variables → Actions에서 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`를 추가합니다. 기존 텔레그램 봇을 재사용할 수 있지만 코인/주식 알림이 같은 채팅에 섞입니다. 새 봇을 만들면 구분됩니다.
6. Settings → Actions → General → Workflow permissions에서 Read and write permissions를 허용합니다.
7. Actions → Fear-RSI STOCK alerts → Run workflow로 시험 실행합니다. 신규 신호가 없다면 알림이 없을 수 있습니다.
8. (선택) Settings → Secrets and variables → Actions → **Variables**에 `WATCH_CODES`를 `005930,000660,035420,247540` 형태로 추가합니다. 미설정 시 기본 관심 종목 4개를 사용합니다.

**주의**: Streamlit 화면에서 변경한 관심 종목은 GitHub Actions 설정에 자동으로 저장되지 않습니다. 자동 알림 감시 종목을 바꾸려면 `WATCH_CODES` 변수도 변경해야 합니다. `.KQ` 종목인데 목록에 없는 종목 코드를 직접 넣으면 코스피로 추정할 수 있어 데이터를 못 가져올 수 있습니다.
